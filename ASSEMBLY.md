# Manual assembly parts

The following parts are not included in the JLCPCB top-side SMD assembly and must be soldered manually.

| Reference | Part |
| --- | --- |
| A1 | Two 1×20, 2.54 mm female socket headers and Waveshare ESP32-S3-ETH-POE module |
| RJ1, RJ2 | Amphenol RJHSE5380 shielded RJ45 connectors |
| J1 | 1×3, 2.54 mm pin header and jumper cap |
| J4 | Phoenix Contact 1844278 8-pin header and compatible mating plug |
| SW1 | RESET push-button |
| SW2 | BOOT push-button |
| SW3 | FW RESET push-button |
| SW4 | CAN termination slide switch |
| TP1–TP3 | CANH, CANL and CAN GND test points |
